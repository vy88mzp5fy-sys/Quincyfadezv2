# QuincyFadez Mobile — Mockup Design Lock

This file is the visual source-of-truth for the current mobile app redesign.

## Core Visual Direction
- Premium near-black background with subtle black-marble texture.
- Warm luxury gold accents, outlines, icons and active states.
- Soft white primary text with muted grey secondary text.
- Dark charcoal cards with rounded corners, subtle borders and restrained shadowing.
- Clean modern sans-serif typography throughout client and admin screens.
- QuincyFadez logo remains a prominent premium brand element.
- Keep spacing generous, layouts uncluttered and information easy to scan.
- Client and admin must feel like the same product, not two separate themes.

## Login / Sign Up
- Centred QuincyFadez logo and brand name.
- Tagline: `Precision. Style. Confidence.`
- Large dark rounded authentication card.
- Icon-led fields with dark input backgrounds.
- Password visibility control.
- Remember Me with remembered email behaviour.
- Forgot Password helper state.
- Solid gold primary Log In / Create Account button.
- Gold-outlined secondary account action.
- `Q U I N C Y F A D E Z` footer treatment.

## Client Navigation
The client bottom navigation remains:
1. Home
2. Bookings
3. Gallery
4. Reviews
5. More

Active navigation is gold with a subtle dark-gold active background. Inactive navigation is muted grey/white.

## Client Home
- Centred QuincyFadez logo with menu and bookings controls.
- Personal greeting followed by a clean supporting line.
- Premium image hero with a strong gold Book Now action.
- Quick-access rows for Book Appointment, My Bookings, Gallery and Reviews.
- Popular Services cards use the same dark/gold design system.
- WhatsApp and Directions remain easy to reach.

## Client Booking Flow
- Centred `Book Appointment` header.
- Service selection uses dark cards with the selected service filled gold.
- Date chips and selected date use the same gold active treatment as Admin Schedule.
- Time selection is grouped into Morning, Afternoon and Evening.
- Selected appointment summary is shown before personal details.
- Personal details, payment verification and booking request all use the same rounded dark-card system.
- Confirmation state remains branded and premium.
- Do not remove live availability, Stripe verification or waiting-list functionality for visual reasons.

## Client Bookings
- Upcoming/Past segmented control.
- Appointment cards use a gold-accent date block, client-facing status pill and clear service/time details.
- Cancellation remains functional and requires a confirmation prompt.
- Empty states use the same premium card treatment with a gold booking CTA.

## Client Gallery
- Large featured cut followed by a premium recent-work grid.
- Image overlays stay dark and minimal so haircut imagery remains the focus.
- Gold numbering, captions and CTA styling remain consistent with the app.

## Client Reviews
- Live Google rating remains connected.
- Rating summary uses a premium dark/gold card.
- Review cards use the same typography, spacing and border system as the rest of the client app.
- Leave A Google Review remains a prominent gold CTA.

## Client Services
- Each service uses an icon, service name, duration, real configured price and gold booking action.
- Do not invent new pricing or service claims.

## Client Profile / Account
- Profile and account cards use the same black/gold system as Admin More/Settings.
- Client notification preferences use gold toggles.
- My Bookings, Services, Directions, WhatsApp, Reviews and Share Booking Link remain accessible.
- Payment method management remains Stripe-backed and functional.

## Admin Navigation
The bottom navigation is fixed as:
1. Dashboard
2. Schedule
3. Insights
4. Clients
5. More

`Insights` permanently replaces the old `Bookings` admin tab.
The active tab is gold; inactive tabs are muted white/grey.

## Dashboard
- Logo centred at the top with menu and notification controls.
- Greeting: `Good morning/afternoon/evening, Quincy`.
- Four dark summary cards in a 2×2 grid.
- Upcoming appointments shown chronologically below.
- Pending booking requests remain actionable.

## Schedule
- Centred `Schedule` title.
- Horizontal date selector with selected day filled gold.
- Chronological appointment cards.
- Time block on the left, client/service in the middle, status on the right.

## Insights
Insights should visually match the approved mockup and use real app data.

Top summary cards:
- This Week’s Revenue
- Bookings This Week
- Repeat Clients
- No-Shows

Sections:
- Top Services, including bookings and completed revenue.
- Peak Hours, with compact visual activity bars.
- Client Insights, including New Clients This Month and Average Spend.
- Where historical data exists, display comparison text against the previous week/month.
- Do not invent performance percentages or placeholder business results in the live app.

## Settings / More
- Centred `Settings` title.
- Gold section headings.
- Dark grouped rows with minimal dividers.
- Gold dropdown arrows and gold active toggles.
- Booking options, notifications/automations, sharing, business profile, services, location and working hours remain interactive.

## Product Rule
New mobile screens must follow this same visual system unless the owner explicitly changes the direction. Avoid introducing unrelated colours, card styles, typography or navigation patterns that make the app feel like a different product.
