# QuincyFadez Mobile App

Official QuincyFadez iOS and Android app, built with Expo and React Native.

## Current build

- Premium black / understated gold QuincyFadez visual system
- Branded home screen
- Main Book Appointment action connected to Barbr
- Service pricing preview
- Gallery shortcut
- Google review shortcut
- WhatsApp contact
- Directions
- Website shortcut
- App identifiers reserved as `com.quincyfadez.app`

## Planned build order

1. Home — first version complete
2. Native Services screen
3. Booking flow integration
4. Gallery
5. Reviews
6. Contact and Directions
7. App navigation
8. Notifications / appointment reminders
9. App icon and splash assets
10. App Store and Google Play production preparation

## Development

This project targets Expo SDK 57 and lives separately from the production website in `/mobile`.

```bash
cd mobile
npm install
npx expo start
```
